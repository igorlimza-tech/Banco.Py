🏦 Banco Py

Simulador de banco desenvolvido em Python via terminal com foco em praticar Programação Orientada a Objetos (POO), organização de código e boas práticas de desenvolvimento.

O projeto foi criado como parte dos meus estudos em Python e está sendo evoluído continuamente com novas funcionalidades.

🚀 Funcionalidades
✅ Cadastro de clientes
✅ Listagem de clientes
✅ Criação de contas bancárias
✅ Listagem de contas
✅ Depósito
✅ Saque
✅ Consulta de saldo
✅ Extrato de operações
✅ Validação de CPF
✅ Validação de telefone
✅ Validação de valores numéricos
✅ Validação para impedir valores negativos ou iguais a zero
🛠 Tecnologias utilizadas
Python 3
Programação Orientada a Objetos (POO)
